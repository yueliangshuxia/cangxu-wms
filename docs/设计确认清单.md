- 视觉上保留现在的工业控制台方向，答辩投影时对比度高、辨识度强；如果导师偏传统，可以把侧栏改浅，但保留安全橙与窄体数字。

- 技术栈选你能持续写下去的。Java 不熟就用 Flask/FastAPI，不要为了“企业级”三个字硬上。
